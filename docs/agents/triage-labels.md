# 分诊标签

各技能以五个规范的分诊角色进行表述。本文件将这些角色映射到本仓库 issue 追踪器实际使用的标签字符串上。

| 规范角色 | 我们追踪器中的标签 | 含义 |
| -------------- | -------------------- | ---------------------------------------- |
| `needs-triage` | `needs-triage`       | 维护者需要评估这个 issue |
| `needs-info`   | `needs-info`         | 等待报告者补充更多信息 |
| `ready-for-agent` | `ready-for-agent` | 已完全明确，可交给 AFK agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix`      | `wontfix`            | 不会处理 |

当技能提到某个角色（例如“打上 AFK-ready 分诊标签”）时，使用本表中对应的标签字符串。

右列可按你实际使用的词汇表修改。
